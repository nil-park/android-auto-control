# 전제 조건

아래는 성립한다고 보고 코드를 쓴다. 어긋나면 방어하지 말고 시작 시점에 즉시 실패한다.

## 실행 환경

- 개발과 실행 모두 Windows PC 한 대에서 한다. 서버로 띄우지 않고 사람이 지켜보는 앞에서 돌린다.
- 동시에 제어하는 폰은 한 대다. 여러 대를 붙이는 경우는 다루지 않는다.
- 폰은 USB로 연결하고, ESP32는 PC에 USB로 꽂혀 있다.

## 폰

- 개발자 옵션과 USB 디버깅이 켜져 있고, PC가 이미 인증된 adb 호스트다.
- 화면 방향은 실행 중에 바뀌지 않는다. 회전 처리를 하지 않는다.
- 화면 해상도와 밀도는 실행 중에 바뀌지 않는다. 좌표 변환 계수는 시작할 때 한 번 구한다.

## 화면 분석

- 찾는 대상은 화면에서 크기와 회전이 변하지 않는다. 템플릿 매칭으로 충분하고, 특징점
  매칭이나 학습 모델은 쓰지 않는다.
- 프레임을 놓쳐도 다음 주기에 다시 보면 되므로, 캡처 스트림의 모든 프레임을 처리하지 않는다.

## 입력 장치

- ESP32는 폰에 이미 페어링되어 있다. 페어링은 사람이 폰 설정에서 미리 해둔다.
- 시리얼 포트는 실행 중에 바뀌지 않는다. 재연결 로직 없이 끊기면 종료한다.
